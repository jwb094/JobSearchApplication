# Job Search Application (React.js)

A responsive job search application built with React.js that enables users to browse, search, filter, sort, and view job listings through a modern and intuitive interface. The application simulates a real-world recruitment platform using dummy data to represent backend API responses and demonstrates scalable React application architecture.

---

## ✨ Features

- Responsive job board interface
- Browse all available job listings
- Search jobs by keyword
- Filter jobs by:
  - Job Type
  - Location
  - Experience Level
  - Salary Range
- Sort jobs by:
  - Latest Posted
  - Oldest Posted
  - A–Z
  - Z–A
- Featured job listings
- Job details page
- Pagination
- Company information
- Related jobs section
- Responsive navigation and footer
- Dummy backend data for jobs, companies, categories, locations, and applications
- Reusable UI components throughout the application

## 📚 Project Purpose

The purpose of this project was to build a realistic job search platform while gaining practical experience with modern React development. The application focuses on creating a scalable, maintainable codebase that mirrors the structure of a production-ready recruitment website.

By building this project, I explored common frontend challenges such as managing application state, implementing search and filtering functionality, handling pagination, organising reusable components, and presenting dynamic data through a responsive user interface.
